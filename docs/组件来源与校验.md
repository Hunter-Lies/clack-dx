**《DirectX End-User Runtimes (June 2010)》**（`directx_Jun2010_redist.exe`），
由 `tools\stage_payload.ps1` 从安装包里的 154 个 cab 逐个解出来，

- `payload\x86\*.dll` → 装到 `C:\Windows\SysWOW64`（32 位游戏读这里）

只补系统目录里**缺**的文件，已存在的一律不覆盖。
